## 필요한 API (미착수, 기획서 3단계)

- `GET /items?level=&since=` 피드, `GET /items/{id}/decision` 판정 근거
- `POST /feedback` (user_id, item_id, verdict) — Discord 리액션과 동일 upsert
- `GET/PUT /me/prefs` 관심사·알림·kind 가중치, `GET/PUT /sources` 토글
- `GET /items/dropped?group=source|kind|stage&since=24h` 걸러진 항목 그룹 집계 + 항목 목록 (relevance×kind 리포트 SQL 재사용), `POST /feedback` 로 버린 항목에도 useful 허용
- `GET/POST/DELETE /bookmarks`, `GET/POST /bookmark-folders`, `PATCH /bookmarks/{id}` (folder·note·read_at). 7일 미열람 찜 재알림은 발송 잡의 silent 레벨로
- `GET /me/stats` 프로필 화면 집계 (weekly_report.py 의 SQL 재사용)

## 열린 결정

- 온보딩 8건은 "최근 72시간 SCORED/SENT 중 kind 가 고른 것"으로 뽑을지
- kind 가중치를 사용자에게 노출할지(현재는 rules.yaml 전역), 노출한다면 숫자 대신 "덜 받기/보통/더 받기" 3단계로
- 프로필 화면의 "놓친 이슈"는 수동 입력(직접 찾아본 건)인지
- 찜을 프로필 벡터의 약한 긍정 신호(암묵 신호, 메모 §3-B)로 넣을지 — 화면에는 "반영 안 함"으로 적어 둠

## 피그마 연동 메모

1. **Figma 커넥터** (claude.ai → 설정 → 커넥터 → "Figma"). 연결하면 `use_figma`(Plugin API 로 프레임 직접 생성·수정), `get_design_context`(프레임 → 코드), `get_screenshot`, `create_new_file`, `generate_diagram`(FigJam) 을 쓸 수 있다. 위 파일이 이 경로로 만들어졌다.
2. **화면을 피그마에 넣는 방법** (편집 가능한 레이어로):
   - 피그마 플러그인 `html.to.design` 설치 → 캔버스 아트보드를 PNG 로 내보내는 대신, 레포에 저장한 `*.dc.html` 각 파일의 `<x-dc>` 안쪽 HTML 을 붙여넣어 임포트. 인라인 스타일이라 레이어·색·간격이 그대로 옮겨진다.
   - 빠르게 참고만 할 때: 캔버스 툴바 Export → PNG 를 피그마에 드롭.
3. 이후 피그마에서 수정한 화면은 커넥터 연결 뒤 "이 프레임을 Next.js 컴포넌트로" 같은 요청으로 `get_design_context` 를 통해 코드로 가져온다.
